# 🎓 StudentHub - AI Powered Student Management System

StudentHub is a modern, full-stack Student Management System built with **Flask**, **SQLite**, **Chart.js**, and an integrated **HubBot AI Agent** for intelligent natural language database querying, student risk analysis, and academic reporting.

---

## ✨ Features

- 🤖 **HubBot AI Assistant**: Floating AI chat widget & full workspace (`/ai-assistant`) to query database, find students, and generate risk reports.
- 📊 **Interactive Analytics Dashboard**: Live Chart.js graphs for course enrollment distribution and student active/inactive ratios.
- 📚 **Course & Department Management**: Full CRUD operations for courses with credit hours, tuition fees, and course codes.
- 📅 **Attendance Tracker**: Log daily attendance (`Present`, `Absent`, `Late`) and track attendance rates.
- 📝 **Subject Gradebook**: Track exam scores with automated letter grade calculation (`A+` to `F`).
- 📥 **CSV Export**: One-click student directory export.
- 🖨️ **Printable Report Cards**: Formally styled academic transcript profile cards.
- 🌙 **Glassmorphism UI & Dark Mode**: Modern aesthetic with theme switcher.

---

## 🛠️ Tech Stack

- **Backend**: Python, Flask, SQLite3
- **Frontend**: HTML5, Vanilla CSS (Glassmorphism design system), JavaScript (ES6+), Chart.js
- **AI Engine**: Natural Language DB Query Parser & Heuristic Insight Generator

## 🚀 Quick Start Guide

### 1. Clone the repository
```bash
git clone https://github.com/YOUR_USERNAME/studenthub.git
cd studenthub
```

### 2. Set up database
```bash
python database_setup.py
```

### 3. Run the application
```bash
python app.py
```
Open **[http://127.0.0.1:5000](http://127.0.0.1:5000)** in your browser.
